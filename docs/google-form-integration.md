# Google Form → Google Sheet → Apps Script → Node.js Webhook Integration

This document describes the technical architecture and setup procedure for integrating Google Form submissions into the **KaushalSaathi Task, Lead & Sales Performance Tracker**.

---

## 1. Architecture Overview

```text
Google Form (User submits enquiry)
       ↓
Google Sheet (Form responses stored in sheet)
       ↓
Google Apps Script (Triggered onFormSubmit)
       ↓
Secure Node.js Webhook (POST /api/integrations/google-form)
       ↓
Zod Validation & Webhook Secret Check (X-Webhook-Secret)
       ↓
Duplicate Detection & Idempotency Check (formResponseId)
       ↓
PostgreSQL Database (Lead created with source="Google Form", status="NEW")
       ↓
Lead Management UI (Managers/Admins assign lead to Counsellors)
```

---

## 2. Webhook Specification

### Endpoint
```text
POST /api/integrations/google-form
```

### Headers
| Header Name | Value | Required | Description |
|---|---|---|---|
| `Content-Type` | `application/json` | Yes | Request payload format |
| `X-Webhook-Secret` | `<YOUR_WEBHOOK_SECRET>` | Yes | Must match `GOOGLE_FORM_WEBHOOK_SECRET` in `backend/.env` |

### JSON Payload Schema
```json
{
  "formResponseId": "resp_9876543210",
  "name": "Kavitha Sharma",
  "phone": "9876543210",
  "email": "kavitha@example.com",
  "course": "Python Full Stack",
  "city": "Hospet"
}
```

#### Field Specifications:
- `formResponseId` *(String, Required)*: Unique submission ID generated by Google Form (`e.response.getId()`). Used as primary idempotency key.
- `name` *(String, Required)*: Full name of the prospect.
- `phone` *(String, Required)*: Contact phone number.
- `email` *(String, Optional)*: Prospect email address.
- `course` *(String, Optional)*: Interested course or program.
- `city` *(String, Optional)*: Prospect city.

## 3. Webhook Responses

### 1. Lead Created Successfully (`HTTP 201 Created`)
```json
{
  "success": true,
  "duplicate": false,
  "potentialPhoneDuplicate": false,
  "message": "Lead created successfully",
  "leadId": "c0a80101-0000-0000-0000-000000000000"
}
```

### 2. Duplicate Submission Handled Idempotently (`HTTP 200 OK`)
If the same `formResponseId` is submitted multiple times (e.g. Apps Script retry):
```json
{
  "success": true,
  "duplicate": true,
  "message": "Lead already exists",
  "leadId": "c0a80101-0000-0000-0000-000000000000"
}
```

### 3. Unauthorized Webhook Request (`HTTP 401 Unauthorized`)
If `X-Webhook-Secret` is missing or invalid:
```json
{
  "success": false,
  "message": "Unauthorized: Invalid or missing webhook secret"
}
```

### 4. Validation Error (`HTTP 400 Bad Request`)
If required fields (`name`, `phone`, `formResponseId`) are missing:
```json
{
  "success": false,
  "message": "Invalid request payload",
  "details": [
    { "field": "phone", "message": "phone cannot be empty" }
  ]
}
```

## 4. Google Apps Script Setup Guide

To connect your Google Form spreadsheet to the KaushalSaathi Webhook:

1. Open the Google Sheet linked to your Google Form.
2. In the menu, go to **Extensions** → **Apps Script**.
3. Replace the editor contents with the following code snippet:

```javascript
// Google Apps Script snippet for KaushalSaathi Lead Tracker Webhook

const WEBHOOK_URL = "https://your-domain.com/api/integrations/google-form";
const WEBHOOK_SECRET = "kaushalsaathi_webhook_secret_dev_2026"; // Match GOOGLE_FORM_WEBHOOK_SECRET

function onFormSubmit(e) {
  try {
    const response = e.response;
    const itemResponses = response.getItemResponses();
    
    const payload = {
      formResponseId: response.getId(),
      name: "",
      phone: "",
      email: "",
      course: "",
      city: ""
    };

    // Map form items to payload fields
    for (var i = 0; i < itemResponses.length; i++) {
      var itemResponse = itemResponses[i];
      var title = itemResponse.getItem().getTitle().toLowerCase();
      var value = itemResponse.getResponse();

      if (title.indexOf("name") !== -1) {
        payload.name = value;
      } else if (title.indexOf("phone") !== -1 || title.indexOf("mobile") !== -1 || title.indexOf("contact") !== -1) {
        payload.phone = value;
      } else if (title.indexOf("email") !== -1) {
        payload.email = value;
      } else if (title.indexOf("course") !== -1 || title.indexOf("program") !== -1) {
        payload.course = value;
      } else if (title.indexOf("city") !== -1 || title.indexOf("location") !== -1) {
        payload.city = value;
      }
    }

    // Fallback if email is collected automatically by Google Form
    if (!payload.email && response.getRespondentEmail()) {
      payload.email = response.getRespondentEmail();
    }

    var options = {
      method: "post",
      contentType: "application/json",
      headers: {
        "X-Webhook-Secret": WEBHOOK_SECRET
      },
      payload: JSON.stringify(payload),
      muteHttpExceptions: true
    };

    var result = UrlFetchApp.fetch(WEBHOOK_URL, options);
    Logger.log("Webhook Response: " + result.getContentText());
  } catch (err) {
    Logger.log("Webhook Error: " + err.toString());
  }
}
```

4. Click **Triggers** (Clock icon on left sidebar) → **Add Trigger**.
5. Set:
   - Choose function to run: `onFormSubmit`
   - Select event source: `From spreadsheet`
   - Select event type: `On form submit`
6. Click **Save** and grant permissions.

## 5. Local Testing Procedure

You can test the webhook locally using `curl` or Postman:

```bash
curl -X POST http://localhost:5000/api/integrations/google-form \
  -H "Content-Type: application/json" \
  -H "X-Webhook-Secret: kaushalsaathi_webhook_secret_dev_2026" \
  -d '{
    "formResponseId": "test-response-001",
    "name": "Ramesh Kumar",
    "phone": "9876543210",
    "email": "ramesh@example.com",
    "course": "Java Full Stack",
    "city": "Hospet"
  }'
```

Re-running the exact command above will test the idempotency handler and return `duplicate: true`.
